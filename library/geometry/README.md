# 整数幾何 API

GNU++23、`cpl::geometry` 名前空間で使用します。座標型は64bit以下の符号付き整数型で、
通常は `Point<long long>` を使います。浮動小数点型・unsigned は扱いません。

| 用途 | ヘッダ | API | 時間 |
| --- | --- | --- | --- |
| 点・ベクトル | `point.hpp` | `Point<T>{x,y}`、`+` / `-` / `+=` / `-=`、比較 | O(1) |
| 内積・外積 | 同上 | `dot(a,b)`、`cross(a,b)`、`cross(a,b,c)` | O(1) |
| 距離の2乗 | 同上 | `norm2(p)`、`dist2(a,b)` | O(1) |
| 3点の向き | `ccw.hpp` | `ccw(a,b,c)` | O(1) |
| 偏角比較・ソート | `polar_angle_sort.hpp` | `polar_angle_less<T>(a,b)`、`polar_angle_sort(points)` | 比較 O(1)、ソート O(N log N) |
| 閉線分 | `segment.hpp` | `Segment<T>{a,b}`、`on_segment(p,s)`、`segments_intersect(s,t)` | O(1) |
| 凸包 | `convex_hull.hpp` | `convex_hull(points, keep_collinear=false)` | O(N log N) |
| 符号付き面積・向き | `polygon.hpp` | `signed_area2(polygon)`、`polygon_orientation(polygon)` | O(N) |

各ヘッダは依存する自作ヘッダ・標準ヘッダを自分で include します。
詳しい引数とコンパイル可能な使用例は各ヘッダの Doxygen にあります。

## 数値の保証

積・外積・距離の2乗・面積の返り値は `Wide`（符号付き `__int128`）です。
3点の外積と距離では、**座標を128bitに変換してから差を取ります**。

- 各座標の絶対値が `M <= 2^62-1` なら、内積・外積・距離・向き・線分・偏角比較・凸包で使う
  全中間値が128bitに収まります。2点間の距離の2乗の上界は `8*M^2` です。
- `Point<T>` 同士の加減算・符号反転は `Point<T>` を返すため、**結果の座標が T に収まること**が別途必要です。
  `cross(a,b,c)` や `dist2(a,b)` を、明示的な `Point<T>` の差に置き換えないでください。
- 面積では、各外積に加えて**逐次加算の途中も128bitに収まること**が必要です。
  `N` 頂点の各座標の絶対値が `M` 以下なら、数学的な `2*N*M^2 <= 2^127-1` は十分条件です。
  例えば `N <= 200000, M <= 10^9` は安全です。この十分条件を満たさなくても、全中間値が収まれば使用できます。
- 一律の座標範囲を超える入力は、呼び出し側で個々の中間値の範囲を保証してください。
  全64bit座標を無条件には扱えません。例えば `(LLONG_MIN,LLONG_MIN)` の `norm2` は `2^127` で、
  符号付き128bitにも収まりません。範囲外の検出や多倍長整数への切り替えは行いません。
- `Wide` は標準の `std::cout` では直接出力できません。小さい型への変換は結果がその型に収まる場合だけ行います。

## 順序と境界ケース

- `Point` の比較は `(x,y)` の辞書順で、座標の完全一致を使います。
- `ccw` は反時計回り `+1`、一直線 `0`、時計回り `-1`。線上の前後関係は区別しません。
- 偏角は原点基準で、正の x 軸から反時計回りに `[0,2π)`。ゼロベクトルが最初、同一方向は短い順です。
  同じ点同士は同値で、比較関数は数値条件の範囲内で狭義弱順序を満たします。
- 線分判定は端点を含みます。端点接触・共線の重なり・長さ0も有効です。
  長さ0の線分上にあるのは端点と一致する点だけです。
- 凸包は入力の重複点を除き、辞書順最小点から反時計回り、始点の再掲なしで返します。
  入力配列を変更しません。`keep_collinear=true` は辺上の点も残します。
  0/1/2点はそのまま辞書順、全点共線なら既定値では両端、`true` では全点を辞書順で返します。
- 多角形の頂点は境界に沿って並べます。末尾の始点の繰り返しは任意です。
  面積の2倍は反時計回りなら正、時計回りなら負、3点未満・面積0なら0です。
  幾何的な面積・回転方向の解釈には単純多角形を前提とします。自己交差時の計算値は代数的面積です。

## スニペット・検証

[スニペット早見表](../../snippets/README.md)から `geometry`、`polar-sort`、`hull`、`segment-cross`、
`ccw`、`polygon-area` を利用できます。

`verify/geometry/` では AOJ の CGL_1_C・CGL_2_B・CGL_4_A・CGL_3_A と、
Library Checker の Sort Points by Argument に対応し、
Library Checker の A+B 形式の回帰テストで数値上限・狭義弱順序・退化ケースも検証します。
AOJ 向けの向き分類・凸包の始点調整と、Library Checker 向けの偏角順の回転は verify 側で行います。

偏角ソートは同方向の点の順序に複数解を許すため、verify-helper が取得する専用 checker で判定し、
固定の期待出力順には依存しません。ローカルテストでは Python の多倍長整数・有理数による
参照実装、Gift wrapping、小規模全探索との比較を行います。
